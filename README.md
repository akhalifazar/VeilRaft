# VeilRaft

VeilRaft utilizes dynamic, cloud-agnostic containerization, auto-scaling clusters, and real-time data processing with a scalable database engine.

With VeilRaft, you get a lightweight tool that stays out of your way.

**What you get**

- VeilRaft utilizes dynamic, cloud-agnostic containerization,
- auto-scaling clusters, and real-time data
- processing with a scalable database

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/VeilRaft.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure VeilRaft, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
